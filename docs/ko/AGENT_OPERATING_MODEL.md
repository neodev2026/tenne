# TENNE 에이전트 운영 모델 (AGENT_OPERATING_MODEL)

## 1. 운영 철학
TENNE는 게임 제품과 자율 개발 하네스를 결합합니다. 에이전트는 명시적인 인간 신뢰 경계 내에서 작동합니다. `main` 브랜치는 인간 신뢰 상태이며, 에이전트의 모든 작업은 격리된 브랜치(`agent/*`)에서 수행되고 인간 검토 없이 병합될 수 없습니다.

## 2. 자율성 보정: 레벨 L1.5
자율성 윈도우는 인간이 승인한 단 하나의 작업으로 제한됩니다:
1. **매니저 에이전트**: 목표와 신뢰 상태를 분석하고, 가치 격차를 식별하여 작업을 제안한 뒤 승인을 대기합니다.
2. **인간 소유자**: 제안을 검토하고 승인 여부를 결정합니다.
3. **엔지니어 에이전트**: 격리된 브랜치에서 승인된 범위만 구현하고 테스트를 작성합니다.
4. **검증 에이전트**: 에이전트의 자체 보고와 무관하게 시스템 증거를 독립적으로 검증합니다.
5. **풀 리퀘스트(PR)**: `PROJECT_STATE.candidate.md`와 함께 인간 검토를 위해 제출됩니다.

## 3. 시맨틱 레이어 및 가드레일
- **시맨틱 레이어**: 도메인 의미는 `semantic/` 디렉터리에 성문화되며, 미정의 항목은 시맨틱 갭으로 관리됩니다.
- **가드레일**: 파괴적 명령어, 무단 범위 확장 및 미검증 변경으로부터 프로젝트를 보호합니다.
