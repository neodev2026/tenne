# TENNE 자율성 모델 (AUTONOMY_MODEL)

## 1. 통제된 자율성 스펙트럼
TENNE에서 에이전트 자율성은 L0(수동 페어 프로그래밍)부터 L4(다중 작업 비감독 자율 실행)까지의 단계적 성숙도에 따라 보정됩니다.

## 2. 현재 보정 상태: 레벨 L1.5
프로젝트는 엄격하게 **레벨 L1.5**에서 운영됩니다:
- 윈도우 크기: **인간이 승인한 단 하나의 작업**.
- 권한 경계: 에이전트는 프로젝트를 분석하고 작업을 제안할 수 있으나, 구현은 명시적 인간 승인 후에만 시작됩니다.
- 승격 규칙: 충분한 자동화 가드레일, 테스트 커버리지 및 기록 증거가 축적될 때만 자율성이 점진적으로 확장됩니다.

## 3. 피드백의 좌측 이동 (Left-Shifting)
반복되는 인간의 피드백은 시스템 좌측으로 이동합니다:
`인간 피드백 → 시맨틱 규칙 → 스킬 가이드 → 결정론적 검증 → 가드레일`.
