# TENNE 제품 목표 (한국어 번역)

> 원문 출처: 루트 [GOAL.md](../../GOAL.md) (정식 영문 출처)

## 제품 목표
설치 없이 공개 URL을 통해 브라우저에서 즉시 플레이 가능한 엄폐 기반 분대 전투 게임 TENNE를 구축합니다. 기존 상용 게임의 독점적 캐릭터, 명칭, 아트워크, 음악, UI 및 코드를 복제하지 않으며 독창적인 에셋 또는 플레이스홀더를 사용합니다.

## 엔지니어링 목표
통제된 소프트웨어 에이전트 자율성 연구:
> 에이전트의 개발 루프를 확장하면서도 결정 과정을 이해 가능하게 유지하고, 검증 가능하며, 신뢰할 수 있는 코드베이스를 의미 있는 인간 통제 하에 두는 방법은 무엇인가?

## 신뢰 모델
- `main` 브랜치는 **인간이 신뢰하는 상태(Human-Trusted State)**를 나타냅니다.
- 에이전트는 격리된 브랜치(`agent/*`)에서 작업하며 `main`에 직접 병합할 수 없습니다.

## 초기 자율성 수준
- 자율성 레벨: **L1.5**
- 자율성 윈도우: **인간이 승인한 단 하나의 작업**.

## 부트스트랩 제약 (T-000)
- T-000은 에이전트 개발 환경(Agent Harness)을 구축하며, 게임플레이 기능을 구현하지 않습니다.
- T-000 완료 후 매니저 에이전트는 `main`을 재검토하여 T-001을 제안합니다.
