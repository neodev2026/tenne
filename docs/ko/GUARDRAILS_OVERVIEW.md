# TENNE 가드레일 개요 (GUARDRAILS_OVERVIEW)

## 1. 안전 및 검증 원칙
가드레일은 프로젝트의 무결성을 보호하고 에이전트 자율성의 안전한 확장을 가능하게 합니다. 에이전트가 반드시 준수해야 하는 운영 경계를 정의합니다.

## 2. 가드레일 범주
- **안전 (`G-001`, `G-002`)**: 파괴적 명령어 차단 및 `main` 브랜치 직접 수정 방지.
- **검증 (`G-003`, `G-004`)**: PR 준비 전 단위 테스트 및 빌드 통과 의무화.
- **게임플레이 (`G-020`)**: 승인된 게임플레이 규칙의 무단 변경 방지.
- **자율성 (`G-030`, `G-031`)**: 1개 작업 자율성 윈도우 및 5개 파일 변경 예산 적용.
- **승인 경계 (`G-040` - `G-042`)**: 신규 의존성, 시맨틱 레이어 변경, 가드레일 수정 시 명시적 승인 요구.
- **컨텍스트 및 관측 가능성 (`G-052`, `G-060` - `G-066`)**: 시맨틱 갭 추측 금지, 기록 무결성, 브랜치 격리, 번역 동기화 보장.

## 3. 집행 의미론 (Enforcement Semantics)
- **BLOCK**: 보호된 전이 또는 작업을 결정론적으로 차단합니다.
- **HUMAN_REVIEW**: 조건을 감지하고 인간 승인을 위해 중단합니다.
- **WARN**: 검증 실패를 발생시키지 않고 진단 경고를 표출합니다.
