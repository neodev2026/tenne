# TENNE 프로젝트 상태 (한국어 번역)

> 원문 출처: 루트 [PROJECT_STATE.md](../../PROJECT_STATE.md) (정식 영문 출처)

## 현재 목표
GOAL-001: 통제된 소프트웨어 에이전트 자율성을 실험하며 브라우저 플레이 가능한 TENNE 전투 게임 구축.

## 현재 단계 및 마일스톤
- 단계: 하네스 부트스트랩 (Harness Bootstrap)
- 마일스톤: M-000 - 에이전트 개발 환경 (Agent Development Environment)
- 현재 작업: T-000 - 하네스 부트스트랩 (진행 중)

## 신뢰 상태
저장소는 에이전트 하네스를 구축하는 부트스트랩 시드를 포함합니다. 제품 게임플레이는 아직 구현되지 않았습니다.

## 명시적 범위 제외 (T-000)
사격, 재장전, 기절, 엄폐, 적, 스킬, 버스트, 스테이지 진행 등 모든 게임플레이 기능은 T-000 범위에서 제외됩니다.
