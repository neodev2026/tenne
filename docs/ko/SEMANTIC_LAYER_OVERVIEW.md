# TENNE 시맨틱 레이어 개요 (SEMANTIC_LAYER_OVERVIEW)

## 1. 시맨틱 레이어의 목적
시맨틱 레이어는 도메인 정의, 게임플레이 규칙, 아키텍처 경계 및 엔지니어링 규칙을 `semantic/` 하위의 구조화된 파일로 성문화합니다. 이는 핵심 프로젝트 의미가 일시적인 프롬프트에만 머무르지 않도록 보장합니다.

## 2. 규칙 도메인
- **제품 (`PS-*`)**: 정체성, 브라우저 실행성, 무설치 요구사항.
- **게임플레이 (`GS-*`)**: 전투 상태 머신, 탄약 처리, 재장전, 기절, 스킬.
- **아키텍처 (`AS-*`)**: 엔진 분리, 무두(Headless) 테스트 가능성, 렌더링 경계.
- **엔지니어링 (`EC-*`)**: 엄격한 타입, 네이밍 규칙, 단일 신뢰 출처.

## 3. 시맨틱 갭 정책 (G-052)
에이전트가 정의되지 않은 게임플레이 수식이나 도메인 동작을 발견하면, 이를 스스로 추측하거나 발명해서는 안 됩니다. 반드시 **시맨틱 갭**으로 등록하고 인간의 결정을 요청해야 합니다.
